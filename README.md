# Gestão Condominial - GitHub Pages

Protótipo estático e responsivo de um sistema para síndico profissional administrar múltiplos condomínios.

## Já funciona
- Dashboard geral
- Lista de condomínios
- Painel interno por condomínio
- Calendário mensal
- Manutenções e recorrência
- Cadastro de nova manutenção
- Alertas por proximidade, com destaque para 2 dias antes
- Chamados
- Tarefas
- Documentos
- Histórico / linha do tempo
- Persistência no localStorage do navegador

## Publicação no GitHub Pages
1. Crie um repositório.
2. Suba os arquivos deste ZIP na raiz do repositório.
3. Vá em Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione main e / (root).
6. Salve.

Não precisa de Node.js, npm ou build.

## Limitação desta versão
É um protótipo 100% frontend. Não possui autenticação real, banco online, notificações reais, WhatsApp, e-mail ou Google Calendar. A evolução natural é conectar Supabase/PostgreSQL.
